# Privacy Policy for SecureX

## Introduction
Your privacy is important. This policy explains how SecureX collects, uses, and protects your information.

## Data We Collect
SecureX is a JavaScript library and **does not collect personal data** by default. Any data processed is under the control of the user.

## Usage Data
- Usage statistics may be collected **only if you opt-in** for analytics (e.g., crash reports).  
- Data collected: library version, error stack traces, environment (Node.js/browser).

## Cookies and Tracking
- SecureX **does not use cookies or tracking scripts**.  
- No telemetry is sent without explicit consent.

## Data Sharing
- SecureX does **not share data with third parties**.  
- Open-source contributions may include publicly visible commit history on GitHub.

## Security of Data
- Any optional data collected is encrypted and stored securely by the user environment.  
- Users are responsible for securing their environment.

## Changes to this Policy
- Updates will be published in `docs/policy/PRIVACY_POLICY.md` and via GitHub releases.  
- Always check the latest version to stay informed.
